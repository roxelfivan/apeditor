# v0.5.4 — Graph view with `[[wikilink]]` term nodes

User-visible release on top of [v0.5.3](https://github.com/roxelfivan/apeditor/releases/tag/v0.5.3). A fourth editor view compiles the workspace into a local knowledge graph. No LLM call, no new npm dependencies, no store-schema migration, and no change to chat / proposed-edit contracts.

## Added

- **Graph** in the Write / Preview / Split dropdown. Replaces the text panes; Format / Comment / Predict hide; File actions and Save stay.
- **Document and heading nodes** compiled from the sidebar and Markdown headings (same heading split as the `@` picker).
- **`[[wikilink]]` term nodes** — `[[Name]]`, `[[Name|label]]`, `[[Name#Heading]]`. Matching titles/headings become edges; unresolved names become term nodes.
- **`@` mention edges** from comment rounds to the referenced document or heading.
- **Explore UX** — hover dims non-neighbors; click a document to open it; click a heading or term to select that span. Clicking a term does not create a document.
- **Help → What's new** — in-app Help now has a page for the current release.

## Behaviour that did NOT change

- Chat prompts, proposed-edit schema / Apply waterfall, JSON backup, OCR, session-only API key.
- `@` mention sentinels are not parsed as wikilinks.

## Verification

- `npm run test:graph` — clean (6 cases).
- `npm run typecheck` — clean.
- `npm run build` — clean.
