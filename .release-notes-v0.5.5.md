# v0.5.5 — Preview wikilinks, Graph polish, Functional Specification

User-visible release on top of [v0.5.4](https://github.com/roxelfivan/apeditor/releases/tag/v0.5.4). Preview renders `[[wikilinks]]` without brackets; Graph Reset re-lays out a tidier atom map; in-app **Functional Specification** for developers; stability fixes so Graph open no longer blanks the tab while typing in Chat.

## Added

- **Preview / Split wikilink display** — `[[Name]]`, `[[Name|label]]`, and `[[Name#Heading]]` render as purple label text (no `[[` `]]`). Alias wins when present; otherwise heading; otherwise target. Write mode still shows the raw syntax. `@` mention sentinels are unchanged.
- **Functional Specification** — top-bar **`{ }`** (or `⌘/Ctrl+Shift+E`) opens the developer guide from `func_spec/`. Separate from Help (`?`). Esc closes either overlay.
- **`npm run check:docs`** — link checker for Functional Specification cross-references.

## Changed

- **Graph Reset** — restores label size and zoom, then remounts and re-lays out nodes (tidy atom layout). Title clarifies the behaviour.
- **Graph layout** — tighter orphan placement and post-relax term re-park on source rays so wikilink chords cross the nucleus less often.

## Fixed

- **Blank tab while Graph is open and Chat is typing** — `ResizeObserver` / chip-rect updates no longer setState with a fresh object on every identical measurement (React max update depth).

## Behaviour that did NOT change

- Chat prompts, proposed-edit schema / Apply waterfall, JSON backup, OCR, session-only API key.
- Graph compile rules (documents, headings, wikilinks, `@` edges). `@` sentinels are still not wikilinks.

## Verification

- `npm run test:graph` — clean (15 cases, including Preview formatting).
- `npm run typecheck` — clean.
- `npm run build` — clean.
