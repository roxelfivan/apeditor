# v0.6.3 — Chat composer attachments

Patch on top of [v0.6.2](https://github.com/roxelfivan/apeditor/releases/tag/v0.6.2). Chat can attach the same photos and PDFs as Import. Recognition stays in the browser. Send builds one format-then-answer prompt. No new dependency, no store-schema migration (attachments are an optional field on `ChatMessage`).

## Added

### Chat **+** attachments

- Hidden file picker next to the chat box, `accept={IMPORT_FILE_ACCEPT}` (`image/*,application/pdf`), shared with toolbar Import.
- In-browser OCR via `extractTextFromFiles`. Files are not inserted into the document.
- One outbound prompt (`buildAttachmentTurnPrompt`): convert extracts to Markdown first, then answer the typed request. No pre-send `formatOcrAsMarkdown()` call.
- Send with text, files, or both. Bubbles and History show filename chips. JSON backups persist name / mime / extract.

### Composer layout

- One bordered field: textarea on top, footer bar with **+** on the left and **Send** on the right.
