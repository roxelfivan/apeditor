# v0.6.2 — Phone layout, chat archives, Graph Filter stacking

Patch on top of [v0.6.1](https://github.com/roxelfivan/apeditor/releases/tag/v0.6.1). Phones (including landscape) get an overlay shell instead of three skinny columns; Chat can collapse turns and archive threads; the Graph Filter checklist stays opaque and above 3D labels. Also includes the Send-to-AI TDZ fix when Chat is collapsed. No new dependency, no store-schema change that requires a migration (JSON backups already gained an optional archive list in #37).

## Added

### Collapsible Chat turns and archive history

- **Click Chat** in the panel header to hide the message list; the input stays. Older prompt/reply turns start collapsed; the latest stays open. **Expand all** / **Collapse older** when there is more than one turn.
- **History** lists the live chat and every archived session for the document. Restore as current, or delete an archive.
- **Archive** parks the live thread without deleting it. The next Send uses only Current. **Clear** still wipes Current without saving.
- JSON backups include archived chats. Older backup files still import (empty archive list).

### Phone / Android overlay shell

Narrow viewports (`max-width: 767px` **or** `max-height: 540px`, so landscape iPhones count) collapse sidebar and chat to overlays. The topbar packs Help / Functional spec / Revisions / Prompts into a **⋯** control that opens a **bottom sheet** (portaled to `document.body`) so it cannot sit under the editor. Edge chevrons have a larger tap target. Settings is full-bleed on narrow screens. Comment composers use the same narrow query as the overlay shell. iOS input zoom is avoided at 16 px.

## Fixed

### Send to AI TDZ when Chat is collapsed (#35)

Sending comments with the chat panel collapsed could throw a temporal-dead-zone error. The send path no longer depends on Chat being mounted.

### Phone ⋯ menu unusable

The overflow menu painted under the editor, then iOS Safari clipped `position: fixed` portals because `overflow: hidden` was on `html`/`body`. The menu is a bottom sheet on `document.body`; overflow clipping stays on `#root` only.

### Graph Filter under node titles

The Filter popover reused translucent mention-picker fills and lived in the toolbar tree, so SVG and 3D HTML labels (z-index up to 2000 for depth) painted through the checklist. Filter now portals to `document.body` with a dim backdrop and solid row fills. The 3D label layer is `isolate`d so its z-index stays inside the graph pane; the Filter root is `z-index: 10000`.
