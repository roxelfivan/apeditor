# v0.5.9 — Graph scope filter, wider zoom / labels, deep-tier compression

Patch release on top of [v0.5.8](https://github.com/roxelfivan/apeditor/releases/tag/v0.5.8). The Graph view gains a **document / section scope filter**, wider zoom and label ranges (which also fix a silent Concept distance clamp), depth-compressed 3D heading tiers for tall `Comment > …` paths, and click reliability fixes so a Graph node actually opens the document.

## Added

- **Filter toolbar control.** A **Filter** button in the Graph toolbar opens a popover (same `.mention-popover*` language as the `@`-section picker) that chooses which documents and which of their headings appear in the graph. Cascading section ticks, All / None / Invert, Clear, and keyboard walk (arrows, Space/Enter, Escape, ⌘/Ctrl+A). An `on` badge appears when the scope is non-empty; **Reset** clears the scope along with label size, zoom, and projection.
- **Pre-layout pruning.** New pure module `src/utils/graph/graphFilter.ts` runs between `buildWorkspaceGraph` and `layoutWorkspaceGraph`, so Flat, Globe, and Concept all inherit the same pruned graph without learning that a filter exists.
- **Empty vs none.** Empty `documentIds` still means *every* document (Reset / All). Unticking the last document (or Invert of everything) emits an explicit none sentinel (`__graph_scope_none__`) so the graph goes empty instead of snapping back to the full workspace. Excluding the current document is allowed; layout re-anchors on the first remaining document.
- **Wider zoom and labels.** Zoom range is **0.25×–12×** (was 0.5×–4×). Label size is **6–48 px** (was 12–28). The 3D label layer clamps to the same range; a test diffs the two so they cannot drift.
- **Concept distance derived from zoom.** `MAX_CONCEPT_DISTANCE = MAX_GRAPH_ZOOM × DEFAULT_CONCEPT_DISTANCE`, so the toolbar can no longer read "1200%" while the camera sits still at an independent ceiling.
- **Depth-compressed 3D tiers.** Shallow outlines keep the full 135-unit gap. Past CommonMark's heading ceiling (`CONCEPT_Z_COMPRESS_AFTER = 6`), each further tier multiplies the gap by `0.82`, floored at `MIN_CONCEPT_Z_STEP = 56`, so a 25-tier `Comment > A > B > …` stack packs into a readable column without interpenetrating.

## Fixed

- **Graph node click opens the document.** In Graph view the textarea is unmounted, so `mvp:select-range` / `restoreCaret` were no-ops. A click now switches to **Split** (from both `GraphView` and the Editor listener) so the caret restore lands.
- **3D click reliability.** `pointerup` raycasts could miss a node that `pointerdown` hit (one-pixel jitter). Concept now captures the down-pick id and fires the click from that id when travel stays under a 5 px drag threshold.

## Behaviour that did NOT change

- **`viewMode`** stays `'write' | 'preview' | 'split' | 'graph'`. Projections remain an inner toggle.
- **The store.** No new persisted fields, no migrations. `graphScope` is local `useState` (same rationale as `graphProjection`).
- **Flat / Globe / Concept data model.** Same nodes and edges; the filter only changes which subset is laid out.

## Known limitations

- **The 3D view is still pointer-only** for navigation (Tab still does not work on `<canvas>`).
- **Filter scope is session-local.** Closing the tab clears it; it is not in the JSON backup.
