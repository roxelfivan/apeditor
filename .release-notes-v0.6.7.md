# v0.6.7 — Chat composer follows the divider

Patch on top of [v0.6.6](https://github.com/roxelfivan/apeditor/releases/tag/v0.6.6). Dragging the thin strip between the conversation and the input no longer leaves a dead gap: **include selection** and the chat box move with the divider, and the typing area grows upward as you drag up.

## Changed

### Chat vertical split

- **Divider = top of the composer.** Drag **up** to grow the input area; drag **down** to shrink it. The messages list fills whatever space remains above via `flex-1`.
- **Include selection sticks to the handle.** The checkbox row sits immediately under the divider; no empty panel strip between them.
- **Input grows with the split.** Once a height is set, the composer is an explicit pixel height; `MentionInput` / the textarea flex to fill the leftover space inside that block (compact `h-24` when unset).
- **Hidden while conversation is collapsed.** The handle is not shown when messages are tucked away (nothing useful to resize between the header and the composer).
- **Persistence.** Still stored under `apeditor:chat-messages-height`. Meaning is now **composer** height (`0` = natural compact size). Values outside `140`–`800` reset to natural height so old message-area sizes do not inflate the input.
