# v0.5.3 — JSON backup, comment Re-link / Dismiss, gated-state polish, Apply waterfall

User-visible release on top of [v0.5.2](https://github.com/roxelfivan/apeditor/releases/tag/v0.5.2) (the internal-only refactor + debug-POST strip). Four feature areas: full JSON backup export; clearer empty / gated-state copy; per-row stale-comment **Re-link** / **Dismiss**; and a streamlined proposed-edit **Apply waterfall** (Exact → Best Effort → Highlight). No prompt / store / LLM-facing contract changes. The session-only API key (`persistApiKey`) is unchanged from v0.5.2.

## Added

- **Export full backup (JSON).** **Export .json** in the file-actions popover downloads the current document plus comments, chat history, and revisions. Versioned payload (`schema: 'apeditor-document-backup'`, `version: 1`); write-only in this release.
- **OCR-vs-key gate copy** on the Import popover — explains what runs locally vs what needs an API key.
- **Empty-state copy in the `@` doc picker** — distinguishes `no-workspace` / `only-current` / `no-match`.
- **Two-step Google AI Mode paste hint** — numbered steps above the paste-answer textarea so first-time users don’t paste their question by mistake.
- **Per-row stale list in the comment tray** — **Re-link** + **Dismiss** per outdated comment, plus **Dismiss all**.
- **`ReanchorPicker`** — pick a heading (or paragraph) to re-anchor a stale comment; ⌘Z reverts.
- **Proposed-edit editor highlight** — paints the matched Exact / Best Effort span while a card is open.

## Changed

- **Proposed-edit Apply waterfall.** One **Apply** button: Exact if the quote matches, otherwise Best Effort. **Highlight Apply** appears only when the editor has a selection (manual override). **Apply N** uses the same waterfall per edit.
- **Form-safer Best Effort.** ~85% coverage gate, section / paragraph expansion, heading re-emit strip (no double-print), residual same-line absorb, and Apply blocked when a splice would duplicate surrounding text.
- **Onboarding / skip copy** now says Highlight Apply instead of Force-apply.

## Fixed

- Removed leftover debug ingest `fetch('http://127.0.0.1:7578/...')` calls from the proposed-edit apply path so they cannot ship in production.

## Behaviour that did NOT change

- Markdown export, OCR pipeline / caps, Google AI Mode URL generation (paste copy only).
- Comment rounds / undo / reanchor store logic (new tray + picker UI only).
- Session-only API key, prompts, and LLM-facing contracts (proposed-edit JSON schema unchanged).

## Verification

- `npm run test:proposed-edit` — clean (7 cases).
- `npm run build` — clean.
