# v0.6.9 — Sidebar tags, Preview numbering, document compare

Patch on top of [v0.6.8](https://github.com/roxelfivan/apeditor/releases/tag/v0.6.8). The Documents sidebar scales past a flat list; Preview/print gain legal-style numbering; **File → Compare…** redlines another file into the existing proposed-edit Apply flow.

## Added

### Sidebar

- **Search** filters by title or tag path.
- **Nested tags** (`#drafts/essays` in the body, or **#** on a row). Folders expand in the sidebar; untagged documents stay in their own section.
- **Star / pin** keeps a document at the top.
- **Recent** lists the last ten opened documents.
- Rename is per-row (pencil / double-click). A single click on **✎** does not open the document or reshuffle Recent.

### Preview / print

- **Lines** — source-line gutter on Preview (and Split-with-Preview).
- **Outline** — heading labels `1 / 1.1 / 1.1.1` or **Article / Section / (a)**. Stored markdown is unchanged.
- **Print** hides sidebar, Chat, and toolbar; Preview keeps lines and outline.

### Document compare

- **File → Compare…** treats the open document as Original and an imported `.md` / `.json` backup / `.docx` (or another workspace document) as Revised.
- Emits a full **proposed-edit** set. Apply / Skip / Apply all use the same waterfall as chat cards. Bulk apply snapshots **Before compare**.

## Notes

- Older documents gain `tags: []`, `starred: false`, and `lastOpenedAt` on load. Hashtags already in the body are picked up automatically.
- `package.json` version bumped to `0.6.9`.
- Tests: `test:tags`, `test:outline-numbering`, `test:document-compare`.
