# v0.6.17 — Select All copies Write or Preview with confirm

Patch on top of [v0.6.16](https://github.com/roxelfivan/apeditor/releases/tag/v0.6.16). The editor toolbar gains **Select All** in Write and Preview. It highlights the live box, then asks before copying to the clipboard.

## Highlights

- **Select All.** Visible in Write and Preview (including Split’s left pane). Hidden in Graph-only mode.
- **Write copies Markdown source.** The textarea is selected (`setSelectionRange(0, length)`), then the confirm dialog shows the captured source.
- **Preview copies rendered text.** The `.prose-md` tree is selected; Copy uses `innerText` (headings without `#`, wikilink labels as shown).
- **Confirm first.** **Copy** writes the captured text; **Cancel**, Escape, or the backdrop leave the clipboard unchanged. Empty documents disable Copy.
