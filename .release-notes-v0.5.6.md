# v0.5.6 — Round-trip JSON backups

Patch release on top of [v0.5.5](https://github.com/roxelfivan/apeditor/releases/tag/v0.5.5). Round-trips the v1 `DocumentBackup` shape introduced in v0.5.3: a backup produced by **Export .json** can be re-imported with comments, chat history, and revisions intact, and the editor switches to the imported document. No behaviour changes outside the new Import path.

## Added

- **Import full backup (JSON)** — new **Import .json** button one popover section below the existing **Export .json** in `FileActionsButton.tsx`. A hidden `<input type="file" accept="application/json,.json">` is the only entry point.
  - **Clean case (no id collisions)** — picks restore in one tap; the popover closes and the editor switches to the imported document.
  - **Id collisions** — a small **Import backup** modal opens with a per-row `<select>` offering **Replace / Skip / Keep both**. Default is **Replace** on collision, **Keep both** otherwise; **Apply** runs the plan and switches to the first kept row; **Cancel** closes the modal with nothing changed.
  - **Keep both** — new uuid, title suffixed `(imported)` (always visible regardless of source title length; the 80-char `sanitizeFilename` cap leaves room for the 11-char suffix).
  - **Inline errors** — size cap (`BACKUP_MAX_FILE_BYTES = 50 MB`), malformed JSON, missing `schema`, unsupported `version`, and cross-record documentId mismatches each surface as a friendly inline error; the popover stays open so the user can retry without re-opening the menu.
- **Bidirectional `DocumentBackup` v1** — `parseDocumentBackup` is the inverse of `serialiseDocumentBackup`. Round-tripping a populated backup (comments, chat history, revisions, mention tokens, comments-with-rounds) produces a deep-equal document state.
- **`npm run test:backup-roundtrip`** — new 19-case esbuild + `node:assert/strict` harness in `scripts/test-backup-roundtrip.mjs`.

## Behaviour that did NOT change

- Chat prompts, proposed-edit schema / Apply waterfall, OCR, session-only API key, Graph view, Preview wikilinks, the Functional Specification.
- Backups produced by v0.5.3 / v0.5.4 / v0.5.5 stay importable unchanged — the wire shape is the same.
