# v0.6.8 — Toolbar polish, compact Mindmap, Preview default

Patch on top of [v0.6.7](https://github.com/roxelfivan/apeditor/releases/tag/v0.6.7). Editor and Graph toolbars get quieter controls; Mindmap packing stays readable when labels grow; first-run opens in **Preview**; propose-edit and Local Model token UI are tidied.

## Changed

### Editor toolbar

- **Predict is icon-only.** Sparkle glyph remains; the word "Predict" is gone (`aria-label` / title still name the feature).
- **Preview Size + / Size −.** Full Preview (and Split-with-Preview) exposes caption font buttons; Write still uses Format → Size.
- **Default view is Preview.** Fresh installs / cleared storage open in Preview (`viewMode: 'preview'`).

### Graph / Mindmap

- **Label size up to 96px.** `MAX_GRAPH_LABEL_PX` raised from 48; 3D clamp matches the SVG range.
- **Magnifier zoom.** Zoom out / Zoom in are icon buttons (no "Zoom" label).
- **Enlarged labels stay on-canvas.** Mindmap SVG pad uses the current world font, not the 16px reference — rightmost titles no longer clip.
- **Compact horizontal packing.** Children pack against *their* parent title (`mindmapChildStep`); a long sibling no longer stretches short branches. Connector / layer floors tightened (`MINDMAP_CONNECTOR` 72, `MINDMAP_LAYER_X` 220).

### Propose-edit + Local Model tokens

- **Reject is a disclosure.** Comment panel and Reject / Reject with feedback appear only when open.
- **Mismatch banner collapses** to one line by default with an expand toggle.
- **Token counters on Local Model.** Chat Send and comment **Send to AI** counters (and preview computation) gate on Local AI / keyless provider — not Debug Mode. Send sits immediately left of the Chat counter.
