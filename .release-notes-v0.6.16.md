# v0.6.16 — Sidebar Collections + collapsible sections

Patch on top of [v0.6.15](https://github.com/roxelfivan/apeditor/releases/tag/v0.6.15). The Documents sidebar gains named **Collections** (multi-membership) and foldable section / collection headings whose open/closed state persists in this browser.

## Highlights

- **Collections.** Create named groups with **＋**, file a document with **📁** (checkbox multi-select), rename / delete from the collection heading. A document can belong to several collections at once.
- **Collapsible chrome.** **Collections**, **Pinned**, **Recent**, **Tags**, **Other** / **All**, and each collection fold with ▸ / ▾; collapsed ids live in `layout.sidebarCollapsedSections` / `layout.sidebarCollapsedGroups` (hidden-when-listed; open by default).
- **Backup round-trip.** Export / import JSON carries `groups` and per-document `groupIds`; import merges collections by name and remaps ids.
- **Search.** The sidebar search box also matches collection names.
