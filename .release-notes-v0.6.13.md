# v0.6.13 — Chat edits imported tables as cells

Patch on top of [v0.6.12](https://github.com/roxelfivan/apeditor/releases/tag/v0.6.12). Spreadsheet tables imported as Markdown can be edited through Chat with cell-addressed proposals instead of fragile prose quotes. Preview tables gain drag-resizable columns with remembered widths.

## Table-aware Chat

When the open document contains a strict GFM pipe table, `buildRequestMessages` emits `sys-table-context` after the proposed-edit rules:

| Path | Behaviour |
|---|---|
| Cloud / eager | Inlines `rN: Col=value` rows (cap 6000 chars) |
| Local Gemma | Compact schema + row count only — cell values stay in `<<<DOCUMENT>>>` |
| Prose-only docs | Block omitted; `PROPOSED_EDIT_SCHEMA_RULES` unchanged |

The document outline collapses each table to one summary line so 60-char truncations of pipe rows are gone.

## `table-edit` fence + Apply

Sibling fence (info-string exactly `table-edit`). Supported operations:

| Op | Effect |
|---|---|
| `set-cell` | One cell by row + column; stale check |
| `delete-rows` / `keep-rows` | Remove a row range (keep inverts to delete) |
| `remove-column` | Drop a column by header or 1-based index |
| `add-column` | Insert a named column at a 1-based position |

Apply uses span / structural helpers — never `findEditAnchor` on short cell strings. **Apply N changes** runs table splices first, then the prose waterfall.

Best Effort `expandToBlockBoundaries` clamps holes inside a data row to that row and stops prose expansion at a table edge.

## Preview column resize

Drag a header’s right edge in Preview. Cell text wraps to the new width. Widths persist in `layout.previewTableColWidths` (browser only — not written into Markdown). Wide tables scroll inside the Preview pane.

## Chat conversation toggle

Collapsing Chat (`+ Chat`) hides the message list. With existing messages the panel auto-expands again so replies are not hidden behind an empty-looking composer; the header shows how many messages are tucked away.
