# ApEditor user guide

ApEditor is a **local-first AI markdown editor**. You write in one window, comment on passages, and ask an AI to propose edits — without creating an account or sending your drafts to an ApEditor server.

This guide is for people using the app. It covers every screen and everyday task.

**In the app:** click **?** in the top bar (or press `Ctrl+/` / `⌘/`) to open these same pages as a themed Help site. Help follows your Light / Dark theme. Developers: click **`{ }`** (or `Ctrl+Shift+E` / `⌘Shift+E`) for the separate Functional Specification.

## What you can do

- Write Markdown in **Write**, **Preview**, **Split**, or **Graph** view
- See [What's new](whats-new.md) for the current release
- Keep many documents in the sidebar
- Comment on a passage, then **Send to AI** in one batch
- Chat with MiniMax, OpenAI, or **Google AI Mode (no key)**
- Review proposed edits as cards — **Apply**, **Reject**, or apply several at once
- Save and restore **revisions**
- Import text from photos or PDFs
- Get optional inline **Predict** suggestions while you type
- Reference other documents with `@` — attach another doc or its headings (`§…`) in chat, comments, or rejection feedback. See [Reference other documents (`@`)](reference-other-documents.md).

## How ApEditor feels different

There is **no sign-in**. Your documents, chats, comments, prompts, and settings live in **this browser** on **this device**. Closing the tab does not erase them. Clearing site data does.

The only network traffic you start on purpose is chat (and Markdown formatting after an import) to the AI provider you chose in Settings.
