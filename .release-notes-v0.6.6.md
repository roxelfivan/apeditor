# v0.6.6 — Mindmap labels that stay readable

Patch on top of [v0.6.5](https://github.com/roxelfivan/apeditor/releases/tag/v0.6.5). The Mindmap projection stops overlapping titles, puts wording above the green connectors, and lets the toolbar **−** / **+** change text size without scaling the whole tree. The retired Globe projection's stereographic math is removed; only the yaw/pitch helpers Concept still needs remain.

## Changed

### Mindmap title layout

- **Line wrap.** A title longer than ~40 columns wraps onto up to four lines instead of running into the next column. Only the title that had to wrap is drawn a little smaller (0.85×); every other title keeps the size you set.
- **CJK-aware width.** Ideographs and full-width glyphs count as two columns, so a Chinese title is no longer treated as half its true width.
- **Column after widest title.** Each child column starts after the *widest* title in the column before it, not after whichever parent happened to be laid out first.
- **Labels above the green line.** Title baselines sit above the connector so wording no longer runs through the stroke.
- **De-overlap pass.** Titles in the same column that would still collide are pushed apart after the tidy-tree placement.

### Mindmap navigation and type size

- **− / + change text size.** The camera scale is pinned to a reference label size. Toolbar **−** / **+** grow or shrink the world font (and re-lay out columns) so text changes relative to nodes and connectors. **Zoom −** / **Zoom +** still scale the whole map.
- **Drag to scroll.** Dragging empty Mindmap space scrolls the tree under the cursor (wheel / trackpad / scrollbars still work).
- **Flat rename.** The radial projection is labeled **Flat** in the toolbar dropdown so it no longer reads as the Graph view itself. Order: Flat → Mindmap → 3D.

### Globe cleanup

- Removed stereographic Globe math (`toSphere` / `toScreen` / `rotateSphere` / `isFrontFacing` / `angularDistance`) from `sphereProject.ts`.
- Removed unused camera orbit state (`orientation`, `'orbit'` drag kind, `SPHERE_RADIUS`) from `useGraphCamera`.
- Kept `dragToOrientation` / `clampPitch` for Concept 3D.
