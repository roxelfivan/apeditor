# v0.6.15 — Phone PWA top bar sits below the status bar

Patch on top of [v0.6.14](https://github.com/roxelfivan/apeditor/releases/tag/v0.6.14). On an iPhone home-screen PWA the top bar no longer disappears under the status bar; time, signal, and battery stay visible, and the logo / document title / buttons sit in the safe area below them.

## Root cause

`viewport-fit=cover` plus `apple-mobile-web-app-status-bar-style: black-translucent` draws the webview under the status bar (so the system icons remain visible). The top bar used a fixed `h-14` and `padding-top: env(safe-area-inset-top)`. Tailwind preflight is `box-sizing: border-box`, so the inset (~47–59px on a notched phone) ate the 56px chrome and left the Preview toolbar as the first visible UI.

## Fix

`.app-safe-top` / `.app-safe-top--bar` pad with `env(safe-area-inset-top)` and set `min-height: calc(3.5rem + inset)` so the controls keep their row height. Help and Functional Specification headers use the same contract. If the top bar is collapsed, the shell still reserves the status-bar band. The top-edge chevron is offset with `.edge-anchor--top`. `theme-color` follows Light / Dark.

## Verification

- `npm run test:safe-area-topbar` — pass.
- `npm run check:docs` — 0 problems.
