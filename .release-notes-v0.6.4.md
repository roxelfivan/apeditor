# v0.6.4 — Local Model (Gemma), Chat attachments

Patch on top of [v0.6.3](https://github.com/roxelfivan/apeditor/releases/tag/v0.6.3). Replaces keyless Google AI Mode with in-browser Local Gemma; first-run default provider is Local Model; Settings hides advanced prompt fields unless Debug Mode is on; **selection only** is removed. Chat **+** attachments ship from v0.6.3.

## Added

### Local Model (LiteRT-LM / WebGPU)

- Settings provider **Local Model (require around 2gb disk space)** (`local-gemma`). Runs `gemma-4-E2B-it-web` in the browser via `@litert-lm/core` + WebGPU.
- Download from Hugging Face into the Cache API, **Load from disk**, **Save to Disk** (picker or browser download), **Last saved** filename + time, **Clear cached model**.
- Download progress shows ApEditor tip copy every 5% (`src/utils/localGemmaTips.ts`).
- First-run / empty-store default provider is `local-gemma` (override with `VITE_DEFAULT_PROVIDER=minimax|openai`). Persisted `google-ai-mode` migrates to `local-gemma`.
- Chat + Comment **Send to AI** use the local engine. Proposed-edit policy is on-demand (prose unless the user asks for edits). Open document is packed for Local Gemma with a `<<<DOCUMENT>>>` envelope on the user turn.
- **Predict** and OCR→Markdown rewrite still need Minimax or OpenAI.

### Chat file attachments

- Composer **+** accepts the same images/PDFs as Import. OCR in-browser; outbound prompt asks for Markdown cleanup then the user request. Bubbles show chips; backups keep extracts.

## Changed

- Removed Google AI Mode paste / URL path (`src/utils/googleAiMode.ts`).
- Removed Chat **selection only** (store flag, UI, prompt branch). **include selection** remains.
- Settings: **System message**, **Rationale rules**, **Temperature** only when **Debug Mode** is on (below Debug Mode + UI font size).
- Proposed-edit cards derive readable titles / ids when the model echoes `"proposed-edit"`.
- Welcome document highlights Local Model as the default and notes Chat **+** / Debug Mode.
