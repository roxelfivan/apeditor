# v0.6.18 — Easier phone and desktop chrome

Patch on top of [v0.6.17](https://github.com/roxelfivan/apeditor/releases/tag/v0.6.17). The workspace is easier to switch on a phone, and the editor view modes are one tap on desktop. Guided by [ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) (touch targets, pointer cursor, visible focus, reduced motion).

## Highlights

- **Phone tab bar.** Narrow / short viewports get a labeled **Documents / Editor / Chat** bar above the home indicator. Overlays sit above it so the tabs stay tappable. Left/right edge chevrons stay on desktop only.
- **View mode tabs.** Write / Preview / Graph / Split are a tab list, not a dropdown.
- **Document title opens Documents.** Click the title in the top bar.
- **Larger phone targets.** Icon buttons, menus, and Chat header actions meet ~44 px on the narrow query.
- **Pointer, focus, motion.** Clickable chrome uses a pointer cursor; keyboard focus is visible; `prefers-reduced-motion` is respected. Theme / More use SVG icons.
