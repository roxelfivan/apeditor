# v0.6.12 — CSV / TSV import: spreadsheet tables as Markdown

Patch on top of [v0.6.11](https://github.com/roxelfivan/apeditor/releases/tag/v0.6.11). The **File** menu gains a third import path: drop an Excel export into the editor and get a Markdown table.

## CSV / TSV import

**File → Import .csv / .tsv** converts a delimited-text file into a GFM pipe table and inserts it at the caret.

| Before (v0.6.11) | After (v0.6.12) |
|---|---|
| No way to bring a spreadsheet in | **Import .csv / .tsv** in the File menu |
| — | One button for both formats — the separator is detected from the file content |
| — | Works with no AI provider configured, and offline |

- Accepts `.csv`, `.tsv`, and `.txt` (some spreadsheet programs export tab-delimited files under a `.txt` name).
- **Separator detection is content-based**, so a tab-delimited file named `.csv` still imports correctly.
- A European export (`Name;Preis` with `3,50` as the decimal) is detected as semicolon-separated, and a comma inside a quoted field is not mistaken for a separator.
- UTF-8 and UTF-16 files (what spreadsheet programs on Windows still emit) are both read correctly.
- The result is ordinary Markdown — editable by hand, covered by revisions, exportable to `.md`, and usable as Chat context.

### Accuracy

The conversion is **literal**. A spreadsheet file carries no type information, so currency, percentages, dates, and codes with leading zeros (`007`) come through exactly as text. Columns are not right-aligned by default, so a column of identifiers is never mistaken for a quantity.

| Cell contains | Right-aligned? |
|---|---|
| `12`, `-5` | Yes (only when alignment is explicitly enabled) |
| `007` | No — a leading zero means an identifier, not a quantity |
| `3.50`, `3,50` | No — ambiguous between a US and an EU decimal |
| `$45.50`, `45%` | No — currency and percentages are not numbers |

### A bug worth naming

GFM keeps consuming lines that look like table rows. A table that is not closed by a blank line **absorbs whatever follows it in the document**, and that content disappears from the rendered page. The converter therefore terminates every table with a blank line, and both test harnesses assert it.

## Preview tables scroll horizontally

Wide tables used to push the whole preview pane sideways. Tables are now wrapped in a horizontally scrollable box (`PreviewMarkdown`'s `table` component → `.table-scroll`), so only the table scrolls.

- The source-line gutter moved from the inner `<table>` onto the wrapper, so the line number stays put instead of scrolling away with the content.
- `rehypeSourceLines` stamps `data-line` on every element it can reach, so a table previously risked one gutter number per cell. Table internals no longer paint numbers.
