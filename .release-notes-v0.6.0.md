# v0.6.0 — Legible 3D, single-row toolbar, refreshed onboarding

Minor release on top of [v0.5.9](https://github.com/roxelfivan/apeditor/releases/tag/v0.5.9). Three user-facing problems are fixed: the 3D Concept projection was unreadable while orbiting **and** had near-invisible dark-mode spheres, the editor toolbar broke onto stacked rows, and the first-run Welcome document was missing most of the feature set. No new dependency, no store-schema change, no migration.

## Fixed

### Graph 3D — labels readable while rotating

Every label rendered at the same size, weight, and ink, at any camera distance, painted in DOM insertion order. Orbiting collapsed the graph into overlapping mush. Four mechanisms now compose inside the existing label loop:

- **Typographic hierarchy by node kind.** Document `1.0` / `700`, heading `0.92` / `600`, term `0.82` / `500`, with terms also dropping to the muted ink. This mirrors the sphere radii (`36` / `20–26` / `16`) that `nodeRadius` already encodes. The **current document** is pinned to `1.0` / `700` so the open page's title stays readable at any orbit angle.
- **Camera-distance ramp.** Opacity `1 → 0.25` and scale `1 → 0.7`. Flat and Globe already faded by `depthScale`; the 3D layer had **no** depth cue at all, so a node 50 units away and one 3000 units away looked identical.
- **Z-order.** `z-index = 2000 · (1 − t)`, derived from the ramp's own `t`, so a node in front always wins an overlap. Previously DOM order decided occlusion, meaning rotating arbitrarily shuffled the winner.
- **Text halo.** A three-pass `text-shadow` in the canvas surface colour — the standard map-label treatment. It follows the light/dark toggle rather than surviving a flip as a fringe.

**Nothing is ever hidden.** Nearest-wins is achieved through paint order and contrast, not removal, so the graph never silently loses wording. The hovered node opts out of the fade entirely — fading it would hide exactly what the user aimed at.

**The ramp is zoom-invariant by construction.** Both bounds are *ratios* of the orbit distance, never absolute distances, so the ramp looks identical at 25% and 1200% and cannot silently disagree with `MAX_CONCEPT_DISTANCE`.

### Graph 3D — dark-mode spheres were invisible

The dark palette used the `ape.*` **surface** tokens — correct as SVG fills, but the 3D canvas is a *lit* surface. Measured against the `ape.base` background:

| Kind | Before | Contrast | After | Contrast |
|---|---|:-:|---|:-:|
| document | `#222932` | 1.23:1 | `#5F738C` | 3.71:1 |
| heading | `#1A2026` | 1.10:1 | `#465767` | 2.43:1 |
| term | `#11171B` | **1.00:1** | `#3A4C58` | 2.03:1 |

`term` was **byte-identical to the background**, so `[[term]]` spheres rendered at `rgb(22,22,22)` on an `rgb(17,23,27)` field — not merely dark, but invisible. A whole-frame luminance histogram put 98.5% of pixels in the darkest eighth of the range, with the two brightest buckets empty.

The three replacements preserve the original **hue and saturation exactly** and raise only lightness, so the cool blue-grey family is unchanged. `document` is the lightest because a hub is the anchor you navigate by. Light mode is untouched.

### Editor toolbar no longer stacks

Both the toolbar row and `GraphViewControls` were `flex-wrap`, which stacked twice over: the controls broke internally at *their own* width, and the outer toolbar broke again at the pane's — dropping Filter / Reset onto a second line and Import / Save onto a third. The overflow point drifted with pane width, so the same controls sat differently at every size.

Both are now `flex-nowrap`, with the controls in a horizontal scroller and Import / Save pinned outside it at `shrink-0`. The old `flex-1 min-w-2` spacer is gone: with a nowrap row it had nothing to push against, and it was the element whose wrap broke the second row.

## Added

- **Welcome document rewritten** — 10 → 12 sections, reordered to follow a natural first-run path. The Graph view (Graph / Globe / 3D, the Filter, `[[wikilink]]` syntax) was documented nowhere in the onboarding despite being a headline feature; JSON/Markdown export and the Re-link / Dismiss stale-comment flow were also missing. The AI section no longer implies a key is required — the whole app works with no AI, which the "degrade, do not block" design treats as intentional.

## Behaviour that did NOT change

- **`viewMode`** stays `'write' | 'preview' | 'split' | 'graph'`. Projections remain an inner toggle.
- **No new state, controls, or dependencies.** There is no label-declutter toggle and no colour picker; both 3D fixes are presentation only.
- **The label size range is still `6–48 px`** and is still clamped *before* per-kind scaling, so the `labelPx` toolbar buttons behave exactly as before.
- **Flat / Globe rendering is untouched** — the depth ramp already existed there.
- **The store.** No new persisted fields, no migrations.

## Internal

- `src/utils/graph/conceptProject.ts` — `conceptLabelStyle`, `conceptLabelDepth`, and their constants. Pure, so the harness asserts them without three.js.
- `src/components/Concept3DScene.tsx` — `ConceptPalette` gains `labelTerm` + `halo`; `labelColor` / `labelHaloCss` helpers; the label loop measures view-space distance **before** `project()` (which mutates in place) and applies hierarchy, fade, and z-order; element creation hoisted above positioning; theme observer refreshes halos; dark-mode sphere colours lifted.
- `src/components/Editor.tsx` / `GraphView.tsx` — toolbar `flex-nowrap` + horizontal scroller; filter popover re-anchors on capture-phase scroll.
- `src/store/defaults.ts` — Welcome document, 12 sections.
- `scripts/test-graph.mjs` — 8 new label cases. Total **83**.
- `func_spec/10-graph-view.md` — label-legibility and single-row-toolbar subsections.
- `func_spec/04-state-and-persistence.md` — starter-document shape, 10 → 12 sections.

> Two invariants worth flagging for future changes. The zoom-invariance test asserts the *property* (`conceptLabelDepth(d·k, pose·k) === conceptLabelDepth(d, pose)`), not the constants, so retuning the ratios stays free. And the existing label-range test parses `Math.max(6, Math.min(48, s.labelPx))` straight out of the scene source — which is why the kind scale had to be applied *after* the clamp rather than folded into it.
