# v0.5.8 — Graph 3D: spread the stack, free navigation

Patch release on top of [v0.5.8](https://github.com/roxelfivan/apeditor/releases/tag/v0.5.8). The 3D Concept projection learned two new things: how to look like a real 3D document outline instead of a flat slab of labels, and how to navigate freely within it.

## Added

- **Spread the y-axis.** Headings now rise **135** units per tier (was 70), so a tall document's `##` columns read as distinct bands. `[[term]]` satellites drop onto an **underground ring at `y = -200`**, so they cannot merge with heading tiers no matter how high the document grows. Documents still sit on the floor at `y = 0`. The slot shape replaced the old `(node id) → number` lookup with `(node id) → ConceptSlot`, which tells the scene whether to branch materials and label offsets for terms.
- **Free 3D navigation via OrbitControls.** `three.js`'s `OrbitControls` is mounted on the scene's canvas and writes back into the same `ConceptPose` the hook already owns:
  - **Mouse wheel** dolly
  - **Shift + drag** pan
  - **Right-drag** pan
  - **Touch**: two-finger drag pans, pinch dollies
  - **Keyboard**: arrow keys pan, `+` / `-` dolly
  - **Damping** (`dampingFactor = 0.08`) for a flick-feel on quick wheel inputs

  Polar-angle clamps are symmetric around π/2 (`MIN/MAX_POLAR_ANGLE = π · {0.08, 0.92}`), so OrbitControls' `phi = π/2 - pitch` matches `clampPitch` exactly. Toggle the camera's distance from a wheel and the toolbar's zoom readout follows it on the same callback — there is still one source of truth for the projection pose.

## Behaviour that did NOT change

- **`viewMode`** stays `'write' | 'preview' | 'split' | 'graph'`. The three projections remain an inner toggle.
- **Flat and Globe** are byte-identical in behaviour, including their focusable `<circle>` nodes.
- **The store.** No new fields, no migrations. `graphProjection` is still local `useState` and still defaults to `'flat'`.
- **Manual node drag** works exactly as before — `controls.enabled` flips to `false` for the duration of a node drag and re-enables on `pointerup`, so the same pointer delta cannot both move a node and orbit the camera (invariant 16).

## Edge zoning

Wikilink and `@` edges no longer route their endpoints to `y = 0`. They follow each endpoint's own `slot.y`, so a heading-to-term chord reads cleanly downward through the negative-y band instead of collapsing onto the floor. This is what lets a tall document have terms hanging visibly under it instead of in a tangle.

## Known limitations

- **The 3D view is still pointer-only** for nav (Tab still does not work on `<canvas>`). Promoting the label layer to a focusable DOM list is the tracked fix from v0.5.8.
- **Wheel direction follows the OS** convention (wheel up zooms in on macOS, wheel down on Windows). The toolbar's `Zoom + / Zoom −` buttons remain the more predictable primary.
- **`graphLabelPx`, `graphZoom`, `graphProjection`, `graphEpoch`** are still non-persisted `useState` in `Editor.tsx`, by design.

## Internal

- `src/utils/graph/conceptProject.ts` — `conceptZForDepth` now `(270 + depth · 135)`; `conceptTermZ` retired in favour of `conceptTermSlot({x, y}): ConceptSlot` which drops a term at `y = -200`; new `conceptPoseFromCamera(eye, target)` is the inverse of `conceptCameraPosition` and is what OrbitControls drives the hook with; new constants `CONCEPT_TERM_DEPTH = 200`, `CONCEPT_TERM_RING_R = 360`, `MIN_POLAR_ANGLE = π · 0.08`, `MAX_POLAR_ANGLE = π · 0.92`; `assignConceptHeights` returns `Map<string, ConceptSlot>` rather than `Map<string, number>`.
- `src/components/Concept3DScene.tsx` — mounts `OrbitControls` (dynamic `import('three/examples/jsm/controls/OrbitControls.js')` so the addon splits into the existing `three.module-*.js` chunk); flips `controls.enabled = false` on pointer-down of a node and back on pointer-up; the per-frame loop ends with `controls.update()` before `renderer.render`, gated on `controls.enabled` so node drags do not damping-decay the camera; edges follow both endpoints' `slot.y` rather than filtering by `e.kind === 'heading'`.
- `src/hooks/useGraphCamera.ts` — `setConceptPose` now also writes the toolbar's `zoom` multiplier when `distance` changes, so a wheel-dolly OrbitControls call surfaces in the readout. Two sources of truth would drift; we keep `zoom` as the source and round-trip a clamped distance out when OrbitControls fires.
- `package.json` — no new dependency (`OrbitControls` ships with `three`). Version bumped to 0.5.9.
- `scripts/test-graph.mjs` — 4 new cases (spacing invariant, sign-of-y invariant, pose round-trip, polar clamps) and 3 rewrites for the new `ConceptSlot` shape. Total **57**.
- `func_spec/10-graph-view.md` — §9d rewritten: two y-bands height table, `ConceptSlot` shape, edge zoning updated to mirror the slot, new **Free navigation** subsection listing gestures. Invariants 15 and 16 added.
- `func_spec/01-product-overview.md`, `03-runtime-flows.md` — version row and runtime flow updated for the two bands and OrbitControls.
